# Bàn thí nghiệm Lab 3 — Hệ thống số (CO1024)

Mô phỏng bàn thí nghiệm kiểu Wokwi: DS-KIT TICKIT, breadboard, IC 74xx (7404, 7408, 7432, 7486, 7474, 7483) và máy hiện sóng Tektronix TBS1052B.

- Bài 1, 3: bộ đếm MOD-16 dùng 7474, giản đồ xung 0000 → 1111.
- Bài 4: đo trễ qua 4 cổng NOT (7404).
- Bài 5: mạch phát hiện cạnh lên.
- Hướng dẫn máy hiện sóng, lắp tự do.

Toàn bộ trang là một file `index.html` (JavaScript thuần, SVG), không cần build.

Số trễ cổng (9,5 ns, 10 ns, 14 ns) là số giả định để minh hoạ. Ảnh DS-KIT lấy từ manual của môn học.
